# nested_cycles.txt — 兩個獨立迴圈並存（無公共節點）
# 結構：
#   迴圈 1（2-gate loop）：C1_A ↔ C1_B
#     c1_b → C1_A → c1_a → C1_B → c1_b
#
#   迴圈 2（3-gate ring）：C2_AB → C2_BC → C2_CA → 回到 C2_AB
#     c2_c → C2_AB → c2_a → C2_BC → c2_b → C2_CA → c2_c
#
# 這個案例驗證：演算法必須對整個圖進行完整搜尋
#   - BFS：兩組閘的 indegree 都不會降為 0 → 兩組都偵測不到，統一回傳 false
#   - DFS：必須從不同連通分量的起始節點分別啟動 DFS，
#           兩次都會碰到 GRAY 節點 → 迴圈偵測
#
# 注意：DFS 的外層 for loop「for (auto& g : gates) if (state[g] == 0) dfs(g)」
#       確保即使圖不連通，所有節點都會被訪問

GATE NOT C1_A c1_b -> c1_a
GATE NOT C1_B c1_a -> c1_b

GATE AND C2_AB c2_c c2_c -> c2_a
GATE AND C2_BC c2_a c2_a -> c2_b
GATE AND C2_CA c2_b c2_b -> c2_c
