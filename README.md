# 麻將聽牌判斷器 (Mahjong Waiting-Tile Analyzer)

## Proposal Report

### 動機與目標

麻將是一種廣泛流行的桌上遊戲，而「聽牌」是遊戲中最關鍵的判斷之一：手持 13 張牌時，需要判斷再摸進哪一張牌即可完成胡牌。這個判斷對新手來說並不容易，即使是有經驗的玩家，在複雜牌型下也可能遺漏聽牌的可能性。

本專題的目標是開發一個 C++ 命令列工具，輸入手牌後自動分析所有聽牌組合，並列出每一張可聽的牌及其對應的拆牌方式。

### 預期功能

1. **手牌輸入與驗證**：透過命令列輸入 13 張手牌（如 `1m 2m 3m 4p 5p 6p 7s 8s 9s 1z 1z 1z 2z`），程式會檢查輸入是否合法（張數、牌種正確性）。
2. **胡牌判斷**：給定 14 張牌，判斷是否能拆解為「1 組雀頭 + 4 組面子（順子或刻子）」的合法胡牌型。
3. **聽牌搜尋**：針對 13 張手牌，窮舉所有可能的第 14 張牌（共 34 種），逐一檢查加入後是否能胡牌，列出所有聽的牌。
4. **拆牌方式展示**：對每種聽牌結果，顯示具體的面子與雀頭拆法。
5. **剩餘張數計算**：根據手牌中已出現的牌，計算每張聽牌在理論上還剩幾張。

### 使用技術

| 技術 | 說明 |
|------|------|
| **Backtracking（回溯法）** | 核心演算法。遞迴嘗試所有可能的拆牌組合（雀頭、順子、刻子），遇到無法繼續拆解時回溯嘗試其他拆法。 |
| **Array / Hash Map** | 使用長度 34 的陣列記錄每張牌的數量，實現 O(1) 的牌數查詢與增減。 |
| **Enumeration（窮舉）** | 聽牌搜尋時，窮舉 34 種牌作為第 14 張加入手牌，逐一進行胡牌判斷。 |
| **Sorting** | 對手牌及輸出結果進行排序，方便閱讀與 debug。 |
| **Struct / Class** | 使用自定義的資料結構表示牌（花色 + 數字）、面子、雀頭等概念。 |

### 時程規劃

| 週次 | 工作內容 |
|------|----------|
| 第 1 週 | 完成 Proposal Report；設計牌的資料結構與輸入解析 |
| 第 2 週 | 實作胡牌判斷（backtracking 拆牌）；實作聽牌搜尋（窮舉 + 判斷） |
| 第 3 週 | 加入拆牌展示與剩餘張數計算；撰寫測試案例 |
| 第 4 週 | 優化與除錯；撰寫 Final Report |

### 與課程的關聯

本專題直接應用了課程中教授的多項核心概念：

- **回溯法（Backtracking）**：課程中討論的遞迴與回溯搜尋策略，是本專題拆牌演算法的核心。每次選擇一種拆法（取雀頭、取順子、取刻子），若後續無法完成則回退嘗試其他路徑，這正是典型的回溯搜尋樹。
- **陣列與雜湊表**：利用陣列作為簡易的雜湊結構，將牌面對應到索引，實現常數時間的查詢與更新。
- **排序（Sorting）**：對手牌與結果排序以利輸出呈現，實際應用課堂所學的排序演算法。
- **抽象資料型別（ADT）**：將麻將牌、面子、手牌等概念封裝為 struct/class，體現課程強調的資料抽象與封裝。
