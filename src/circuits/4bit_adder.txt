# 4-bit 加法器（串接 4 個全加器）
INPUT A0 A1 A2 A3 B0 B1 B2 B3 Cin
OUTPUT S0 S1 S2 S3 Cout

# bit 0
GATE XOR XOR_0a A0 B0 -> T0
GATE XOR XOR_0b T0 Cin -> S0
GATE AND AND_0a A0 B0 -> G0
GATE AND AND_0b T0 Cin -> P0
GATE OR  OR_0   G0 P0  -> C0

# bit 1
GATE XOR XOR_1a A1 B1 -> T1
GATE XOR XOR_1b T1 C0 -> S1
GATE AND AND_1a A1 B1 -> G1
GATE AND AND_1b T1 C0 -> P1
GATE OR  OR_1   G1 P1 -> C1

# bit 2
GATE XOR XOR_2a A2 B2 -> T2
GATE XOR XOR_2b T2 C1 -> S2
GATE AND AND_2a A2 B2 -> G2
GATE AND AND_2b T2 C1 -> P2
GATE OR  OR_2   G2 P2 -> C2

# bit 3
GATE XOR XOR_3a A3 B3 -> T3
GATE XOR XOR_3b T3 C2 -> S3
GATE AND AND_3a A3 B3 -> G3
GATE AND AND_3b T3 C2 -> P3
GATE OR  OR_3   G3 P3 -> Cout
